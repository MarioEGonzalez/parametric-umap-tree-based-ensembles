# Jacket bolt-loosening classification: PCA and Parametric UMAP

Companion research scripts and **audited result summaries** for the Wiley manuscript on experiment-wise bolt-loosening classification in jacket-type wind-turbine structures.

## Contents

- `scripts/`: selected analysis and model-training scripts; original algorithms and hyperparameter settings are retained.
- `results/`: selected verified external OOF metrics, folds, experiment-wise error records, and paired PUMAP ExtraTrees/CatBoost predictions.
- `verification_checks.json`: integrity checks performed on the supplied final analysis.
- `data/`: instructions for locating original experimental data. Original recordings are not redistributed.

**No confusion-matrix files or directories are distributed or generated by the classifier scripts.**

## Execution

Python 3.10 is recommended to match the research environment. Create an isolated environment and install compatible dependency versions; `requirements.txt` lists required packages but is **not an exact lockfile**. Parametric UMAP and TensorFlow compatibility should be checked before installing.

1. Provide original authorized vibration recordings under `data/A_1/` with the source class subdirectories expected by `00_prepare_fft_and_group_folds.py`.
2. Run `00_prepare_fft_and_group_folds.py` to prepare FFT features and group-disjoint folds.
3. Run `01_train_parametric_umap.py` and `02_train_pca_baseline.py` to generate representations.
4. Run `03_train_lightgbm_extratrees.py` on the selected embeddings, followed by the remaining classifier scripts and the audits. The required upstream embeddings must be supplied or generated using the documented representation workflows.

You may override the project root through the `WILEY_PROJECT_DIR` environment variable. Scripts still require the original upstream output directory layout described in their source. Some model-stage scripts require substantial CPU/GPU resources.

## Important reproducibility limitations

These curated files do **not** yet constitute an independently validated end-to-end rerun. The original LightGBM/ExtraTrees training script has now been included. Some result-audit scripts therefore require intermediate model outputs that are not included. Full window-level predictions for all ten pipelines are also not included. Do not represent this repository as complete executable reproduction until these assets are supplied and the entire pipeline has been run and compared against the published numbers.

Verified supplied results include 3,840 held-out windows per model, 50 errors for PUMAP+ExtraTrees and PUMAP+CatBoost, and 60 for PCA+XGBoost. See `results/` for provenance and selected metrics.

## LightGBM and ExtraTrees

`scripts/03_train_lightgbm_extratrees.py` retains the original training and tuning grids, five-fold OOF integrity checks, and 32-dimensional representation inputs. The project root can be set with `WILEY_PROJECT_DIR`. Its confusion-matrix values are still computed in memory for integrity validation but are not written to disk. The script has passed a syntax check; the full pipeline has not been re-executed here.
